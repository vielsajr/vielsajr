Orientada a Objetos

Clases, objetos, constructores, herencia, interfaces y patrones de POO en PHP a partir de la versión 5.

01 Introducción

El lenguaje PHP original no se diseñó con características de orientación a objetos. Las características de POO que se soportan a partir de PHP 5 (actualmente estamos en la 8.4) incluyen:

  • Métodos estáticos
  • Métodos constructores y destructores
  • Herencia
  • Interfaces
  • Clases abstractas

No se incluye:

  • Herencia múltiple
  • Sobrecarga de métodos
  • Sobrecarga de operadores

02 Las clases. Usos de clases

La declaración de una clase en PHP se hace utilizando la palabra class. Entre llaves deben figurar los miembros: primero los atributos, después los métodos.

class Producto
{
    private int $codigo;
    public string $nombre;
    protected float $PVP;

    public function __toString()
    {
        return "{$this->nombre}";
    }
}

Desde PHP 7.4+ los atributos deben inicializarse. Podemos usar:

  • Valores por defecto: private int $codigo = 0;
  • Constructor: public function __construct(int $c, string $n, float $p){...}
  • Nullable: private ?int $codigo = null;

Recomendaciones:

  • Cada clase en un fichero distinto.
  • Los nombres de las clases deben comenzar por mayúsculas para distinguirlos de los objetos y otras variables.
  • Por lo general, los atributos deben ser privados.

03 Objetos. Declaración y usos

Una vez definida la clase, usamos la palabra new para instanciar objetos:

$p = new Producto();

Para que la línea anterior se ejecute sin error, previamente debemos haber declarado la clase:

require_once('producto.class.php');

Para acceder desde un objeto a sus atributos o métodos se usa el operador flecha (solo se pone $ delante del nombre del objeto):

$p->nombre = "Samsung Galaxy S25";
echo $p;

04 Constructores

Se pueden definir métodos constructores que se ejecutan cuando se crea el objeto. El constructor debe llamarse __construct.

public function __construct()
{
}

4.1 Operador this

Cuando desde un objeto se invoca un método de la clase, se le pasa siempre una referencia al objeto que hizo la llamada. Esta referencia se almacena en la variable $this.

Se utiliza para tener acceso a los atributos privados del objeto (solo accesibles desde los métodos de la clase).

echo "<p>" . $this->codigo . "</p>";

El constructor puede tener parámetros, que deberán pasarse al crear el objeto. Solo puede haber un constructor en cada clase.

public function __construct(int $codigo, string $nombre, float $precio)
{
    $this->codigo = $codigo;
    $this->nombre = $nombre;
    $this->PVP = $precio;
}
Ejercicio: Crea un constructor para tu clase Producto.

4.2 Constructores en PHP 8

Una novedad de PHP 8 es la promoción de las propiedades del constructor: se puede declarar atributos y asignarles valores en una sola línea dentro del constructor.

Antes de PHP 8:

class Persona {
    private string $nombre;
    private int $edad;
    private string $ciudad;

    public function __construct(string $nombre, int $edad, string $ciudad) {
        $this->nombre = $nombre;
        $this->edad = $edad;
        $this->ciudad = $ciudad;
    }
}

$persona = new Persona("Pepe", 30, "Oviedo");

Con PHP 8:

class Persona {
    public function __construct(
        private readonly string $nombre, // readonly = solo lectura, se asigna una vez
        private int $edad,
        private string $ciudad
    ) {}
}

$persona = new Persona("Pepe", 30, "Oviedo");

4.3 Destructores

Es posible definir un método destructor, llamado __destruct, que define acciones que se ejecutarán cuando se elimine el objeto (cerrar conexiones, liberar recursos, guardar logs, etc.).

05 Métodos get y set

Aunque no es obligatorio, el nombre del método que permite obtener el valor de un atributo suele empezar por get y el que permite modificarlo por set:

public function setCodigo(int $nuevoCodigo)
{
    $this->codigo = $nuevoCodigo;
}

public function getCodigo(): int { return $this->codigo; }
Ejercicio: Crea los métodos get y set para la clase Producto.

06 Constantes

En una clase también se pueden definir constantes usando la palabra const.

  • No pueden cambiar su valor.
  • No usan el carácter $.
  • Están asociadas a la clase, no a cada objeto.
  • Sus nombres suelen escribirse en mayúsculas.

Para acceder a ellas, se usa el nombre de la clase y el operador de resolución de ámbito :::

class BaseDatos{
    const USUARIO = "dwes";
    ...
}

echo BaseDatos::USUARIO;

No es necesario que exista ningún objeto de una clase para acceder al valor de sus constantes.

Ejercicio: Crea una clase BaseDatos con constantes para el dominio, usuario, contraseña y nombre de la base de datos.

07 Métodos estáticos

Una clase puede tener atributos o métodos estáticos (también llamados de clase). Se definen usando la palabra clave static y se referencian con ::.

class Producto{
    private static $numProductos = 0;
    public static function nuevoProducto(){
        self::$numProductos++;
    }
    ...
}
  • Los atributos y métodos estáticos no pueden ser llamados desde un objeto con el operador ->.
  • Si son públicos, se accede con el nombre de la clase y ::: Producto::nuevoProducto();
  • Si son privados, solo se accede desde los métodos de la clase usando la palabra self: self::$numProductos++;

Ejemplo completo con contador en constructor y destructor:

class Producto{
    private static $numProductos = 0;
    private $codigo;
    public function __construct(string $codigo){
        $this->codigo = $codigo;
        self::$numProductos++;
    }
    public function __destruct(){
        self::$numProductos--;
    }
    public static function getNumeroProductos(){
        return self::$numProductos;
    }
}

$p = new Producto('Iphone');
echo Producto::getNumeroProductos();

08 Utilización de objetos

Una vez creado un objeto, puedes usar el operador instanceof para comprobar si es o no una instancia de una clase determinada:

if ($p instanceof Producto){
    ...
}

Copia de objetos

Desde PHP5, al asignar un objeto a otra variable ($a = $p;) se crea un nuevo identificador del mismo objeto. Cualquier cambio se refleja en ambas variables.

Para copiar un objeto realmente, se usa clone:

$p = new Producto();
$p->nombre = 'Xiaomi 14';
$a = clone $p;

Para personalizar la copia, se puede crear el método __clone() en la clase, que se llama automáticamente después de copiar los atributos.

Comparación de objetos

  • Operador ==: dos objetos son iguales si son instancias de la misma clase y sus atributos tienen los mismos valores.
  • Operador ===: el resultado es true solo cuando las dos variables sean referencias al mismo objeto.
$p = new Producto();
$p->nombre = 'Xiaomi 14';
$a = clone $p;
// $a == $p  → verdadero (mismos valores)
// $a === $p → falso (no son el mismo objeto)
$a = $p;
// $a === $p → verdadero (ahora son el mismo objeto)

09 Herencia. Redefinición de métodos

La herencia permite definir nuevas clases en base a una ya existente (subclases). La clase de la que heredan se llama clase base o superclase.

class Persona{
    protected $nombre;
    protected $apellidos;
    public function __toString(){
        return "<p>" . $this->nombre . "," . $this->apellidos . "</p>";
    }
}

class Alumno extends Persona{
    private $notas;
}
Ejercicio: Codificar estas dos clases y crear un objeto de tipo Alumno. Comprobar mediante instanceof si el objeto es de tipo Persona o de tipo Alumno.

Funciones útiles para la herencia:

  • get_parent_class: devuelve el nombre de la clase padre.
  • is_subclass_of: devuelve true si el objeto tiene como clase base a la indicada.
echo "La clase padre es:" . get_parent_class($p);

if (is_subclass_of($t, 'Producto'))
{
    ...
}

La nueva clase hereda todos los atributos y métodos públicos de la clase base, pero no los privados.

Para crear en la clase base un método no visible al exterior pero que se herede a las subclases, se usa la palabra protected.

Se puede redefinir el comportamiento de los métodos existentes en la clase base, simplemente creando en la subclase un nuevo método con el mismo nombre:

class Profesor extends Persona{
    private $horas;
    public function __toString(){
        return "<p>" . $this->nombre . "," . $this->apellidos . ":" . $this->horas . "</p>";
    }
}

Modificadores final y abstract

final: evita que las clases heredadas puedan redefinir métodos. También se puede declarar una clase entera como final (no se podrán crear clases heredadas).

// Método final
public final function __toString(){ ... }

// Clase final
final class Persona{ ... }

abstract: obliga a que se herede. Una clase con abstract no puede tener objetos que la instancien, pero sí puede usarse como clase base. Un método abstract debe ser redefinido obligatoriamente por las subclases y no puede contener código.

abstract class Persona{ ... }

class Persona{
    ...
    abstract public function mostrar();
}

Llamar al constructor de la clase base

Desde PHP7, si la clase heredada no tiene constructor propio, se llama automáticamente al constructor de la clase base. Si la clase heredada define su propio constructor, debe llamarse al de la base manualmente usando parent y el operador de resolución de ámbito:

class Alumno extends Persona{
    private $notas;
    public function __construct($nombre, $apellidos, $notas){
        parent::__construct($nombre, $apellidos);
        $this->notas = $notas;
    }
}

10 Interfaces

Un interface es similar a una clase vacía que solo contiene declaraciones de métodos. Se definen usando la palabra interface.

interface iMuestra{
    public function muestra(): string;
}

Las clases que lo implementen usan la palabra implements:

class Profesor extends Persona implements iMuestra{
    ...
    public function muestra(): string
    {
        return "<p>" . $this->nombre . ": " . $this->horas . "</p>";
    }
    ...
}
  • Todos los métodos declarados en un interface deben ser públicos.
  • Los interfaces pueden contener constantes pero no atributos.
  • Un interface es como un contrato que la clase debe cumplir.

Desde PHP7 es posible que una clase implemente varios interfaces (separados por comas). La única restricción es que los nombres de los métodos a implementar no coincidan:

class Profesor extends Persona implements iMuestra, Countable{
    ...
}

También se pueden crear nuevos interfaces heredando de otros existentes con extends.
