01 Utilización de bases de datos relacionales

PHP soporta más de 15 sistemas gestores de bases de datos: SQLite, Oracle, SQL Server, PostgreSQL, IBM DB2, MySQL, etc.

1.1 MySQL / MariaDB

MySQL es un sistema de gestión de bases de datos relacional desarrollado bajo licencia dual (Licencia pública general / Licencia comercial) por Oracle Corporation. Está considerada la base de datos de código abierto más popular del mundo.

MariaDB es un sistema de gestión de bases de datos derivado de MySQL con licencia GPL. Es desarrollado por Michael (Monty) Widenius —fundador de MySQL—, la fundación MariaDB y la comunidad de desarrolladores de software libre.

Ambas bases de datos incorporan múltiples motores de almacenamiento:

  • MyISAM (Aria en MariaDB): motor que se utiliza por defecto. Muy rápido pero no contempla integridad referencial ni tablas transaccionales.
  • InnoDB (XtraDB en MariaDB): algo más lento pero sí soporta integridad referencial y tablas transaccionales.

02 Módulos para la gestión del acceso a datos

  • Hasta la versión 5 de PHP, el acceso a las bases de datos se hacía principalmente mediante extensiones nativas específicas para cada sistema gestor.
  • A partir de la versión 5 se introdujo PDO (PHP Data Objects): extensión para acceder de forma común a distintos sistemas gestores.

La gran ventaja de PDO es que podemos seguir utilizando la misma sintaxis aunque cambiemos el motor de base de datos. Las extensiones nativas ofrecen más potencia y en algunos casos mayor velocidad, pero PDO ofrece portabilidad.

2.1 MySQLi

Esta extensión se desarrolló para aprovechar las ventajas de las versiones 4.1.3 y posteriores de MySQL. Ofrece una interfaz de programación dual (objetos o funciones).

Utilizando objetos:

$conexion = new mysqli('localhost', 'usuario', 'contraseña', 'base_de_datos');
print $conexion->server_info;

Utilizando funciones:

$conexion = mysqli_connect('localhost', 'usuario', 'contraseña', 'base_de_datos');
print mysqli_get_server_info($conexion);

2.2 PHP Data Objects (PDO)

PDO se basa en las características de orientación a objetos de PHP. Al contrario que MySQLi, no ofrece interfaz de programación dual: hay que emplear obligatoriamente los objetos con sus métodos y propiedades.

Nosotros trabajaremos con PDO.

03 Establecimiento de conexiones

Para establecer una conexión con PDO hay que instanciar un objeto de la clase PDO con los siguientes parámetros (solo el primero es obligatorio):

  • Origen de datos (DSN).
  • Nombre de usuario con permisos para establecer la conexión.
  • Contraseña del usuario.
  • Opciones de conexión (array).
$dwes = new PDO('mysql:host=localhost;dbname=dwes', 'dwes', 'abc123.');

El origen de datos (DSN) es una cadena de texto que indica qué controlador se va a utilizar. Para el controlador MySQL, los parámetros separados por ; son:

  • host: nombre o dirección IP del servidor.
  • port: número de puerto TCP.
  • dbname: nombre de la base de datos.
  • unix_socket: socket de MySQL en sistemas Unix.

Para indicar codificación UTF-8:

$opciones = array(PDO::MYSQL_ATTR_INIT_COMMAND => "SET NAMES utf8");
$dwes = new PDO('mysql:host=localhost;dbname=dwes', 'dwes', 'abc123.', $opciones);

04 Recuperación y utilización de conjuntos de resultados

Para consultas que generan un conjunto de datos (SELECT) se usa el método query, que devuelve un objeto de la clase PDOStatement:

$dwes = new PDO("mysql:host=localhost;dbname=dwes", "dwes", "abc123.");
$resultado = $dwes->query("SELECT producto, unidades FROM stock");

Para tratar el conjunto de resultados se usa el método fetch:

$resultado = $dwes->query('SELECT campo1, campo2 FROM tabla WHERE condicion');
while ($registro = $resultado->fetch())
{
    echo $registro['campo1'].": ".$registro['campo2']."<br />";
}

El método fetch admite un parámetro opcional para cambiar su comportamiento:

ConstanteComportamiento
PDO::FETCH_ASSOCDevuelve solo un array asociativo.
PDO::FETCH_NUMDevuelve solo un array con claves numéricas.
PDO::FETCH_BOTHDevuelve array con claves numéricas y asociativas (por defecto).
PDO::FETCH_OBJDevuelve un objeto con propiedades correspondientes a los campos.
PDO::FETCH_LAZYDevuelve tanto el objeto como el array con clave dual.
PDO::FETCH_BOUNDDevuelve true y asigna valores del registro a variables (con bindColumn).

Ejemplo con FETCH_OBJ:

$resultado = $dwes->query('SELECT campo1, campo2 FROM tabla WHERE condicion');
while ($registro = $resultado->fetch(PDO::FETCH_OBJ))
{
    echo $registro->campo1.": ".$registro->campo2."<br />";
}

Ejemplo con FETCH_BOUND:

$resultado = $dwes->query('SELECT campo1, campo2 FROM tabla WHERE condicion');
$resultado->bindColumn(1, $campo1);
$resultado->bindColumn(2, $campo2);
while ($registro = $resultado->fetch(PDO::FETCH_BOUND))
{
    echo $campo1.": ".$campo2."<br />";
}

4.1 Consultas preparadas

Para preparar la consulta se usa el método prepare de la clase PDO, que devuelve un objeto PDOStatement.

Con parámetros marcados por signos de interrogación:

$consulta = $dwes->prepare('INSERT INTO tabla (campo1, campo2) VALUES (?, ?)');

Con parámetros con nombre (precedidos por :):

$consulta = $dwes->prepare('INSERT INTO tabla (campo1, campo2) VALUES (:cm1, :cm2)');

Enlace de parámetros con bindParam:

$campo1 = "valor_campo1";
$campo2 = "valor_campo2";
$consulta->bindParam(1, $campo1); // o $consulta->bindParam(:cm1, $campo1);
$consulta->bindParam(2, $campo2); // o $consulta->bindParam(:cm2, $campo2);

Ejecución de la consulta preparada:

$consulta->execute();

05 Ejecución de consultas

Para sentencias SQL que no devuelven datos (INSERT, DELETE, UPDATE), el método exec devuelve el número de registros afectados:

$registros = $dwes->exec('DELETE FROM stock WHERE unidades=0');
echo "<p>Se han borrado $registros registros.</p>";

06 Transacciones

Por defecto PDO trabaja en modo "autocommit" (confirma automáticamente cada sentencia). Para trabajar con transacciones, PDO incorpora tres métodos:

  • beginTransaction: deshabilita el modo "autocommit" y comienza una nueva transacción.
  • commit: confirma la transacción actual.
  • rollback: revierte los cambios llevados a cabo en la transacción actual.

Una vez ejecutado un commit o rollback, se vuelve al modo de confirmación automática.

$ok = true;
$dwes->beginTransaction();
if($dwes->exec('DELETE …') == 0)  $ok = false;
if($dwes->exec('UPDATE …') == 0)  $ok = false;
…
if ($ok) $dwes->commit();   // Si todo fue bien confirma los cambios
else $dwes->rollback();     // y si no, los revierte

07 Errores y manejo de excepciones

PHP define una clasificación de los errores y ofrece métodos para ajustar su tratamiento. Cada nivel se identifica por una constante (por ejemplo, E_NOTICE para avisos y E_ERROR para errores fatales).

La configuración se realiza en php.ini. Principales parámetros:

  • error_reporting: indica qué tipos de errores se notificarán. Por defecto: E_ALL & ~E_NOTICE.
  • display_errors: en su valor por defecto (On), envía mensajes a la salida estándar. Se debe desactivar (Off) en servidores de producción.

7.1 Excepciones

PHP tiene un modelo de excepciones similar al de otros lenguajes:

  • El código susceptible de producir errores se introduce en un bloque try.
  • Cuando se produce un error, se lanza una excepción con la instrucción throw.
  • Después del bloque try debe haber como mínimo un bloque catch encargado de procesar el error.
  • Si no se lanza ninguna excepción, la ejecución continúa en la línea siguiente al bloque catch.
try {
    if ($divisor == 0)
        throw new Exception("División por cero.");
    $resultado = $dividendo / $divisor;
}
catch (Exception $e) {
    echo "Se ha producido el siguiente error: ".$e->getMessage();
}

La clase PDO permite definir cómo actuará ante errores mediante PDO::ATTR_ERRMODE:

ModoDescripción
PDO::ERRMODE_SILENTNo se hace nada cuando ocurre un error (comportamiento por defecto).
PDO::ERRMODE_WARNINGGenera un error de tipo E_WARNING cuando se produce un error.
PDO::ERRMODE_EXCEPTIONLanza una excepción PDOException cuando se produce un error.

Para utilizar excepciones con PDO:

$dwes->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

Ejemplo completo capturando una excepción PDO (tabla que no existe):

$dwes = new PDO("mysql:host=localhost; dbname=dwes", "dwes", "abc123.");
$dwes->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
try {
    $sql = "SELECT * FROM tablaincorrecta";
    $result = $dwes->query($sql);
    …
}
catch (PDOException $p) {
    echo "Error ".$p->getMessage()."<br />";
}
