PHP — Fundamentos del lenguaje

Lenguajes embebidos en HTML, sintaxis PHP, variables y tipos de datos, operadores, funciones, fechas y superglobales.

01 Lenguajes embebidos en HTML

  • Estructura páginas estáticas: sencilla, con tres partes: Cabecera (definición directivas), Zona metadatos, Cuerpo del documento.
  • Una vez creada la página se inserta el código a compilar e interpretar por el servidor.
  • El código de servidor se ejecutará al procesar la petición HTTP del cliente.

1.1 Ámbito de ejecución

  • Los lenguajes de servidor solo pueden tener acceso a los recursos alojados en el servidor o bien otros ofrecidos a través de la red.
  • NO pueden acceder a recursos del propio cliente.
  • Poseen archivos de configuración para definir el comportamiento de la aplicación (php.ini).

02 Tecnologías asociadas: PHP

  • PHP — Hypertext Preprocessor.
  • Lenguaje de código abierto.
  • Permite su uso junto con documentos HTML mediante la inserción de fragmentos de código PHP acotados por etiquetas especiales.
  • El código PHP es interpretado por el servidor web y genera el correspondiente código HTML para mostrar en el navegador.
  • Las páginas tienen extensión .php.
  • Tiene una interfaz de desarrollo basada en la POO.
  • Es compatible con diferentes tecnologías y admite los principales servidores web y diferentes repositorios de BD.

03 Obtención del lenguaje de marcas para mostrar en el cliente

La incrustación de código PHP en HTML más utilizada (compatible con todas las plataformas):

<?php
    ...
?>

Ejemplo completo:

<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8">
        <title>Desarrollo web</title>
    </head>
    <body>
        <h1>Desarrollo en servidor</h1>
        <h2>estas líneas están escritas en HTML</h2>
        <p>esta es una línea incluida en el cuerpo de la página</p>

        <?php
            $expresion="1";
            if ($expresion =="1"){
                echo "1.- Empiezan líneas generadas por PHP <br>";
                echo "2.- El texto está por instrucción print de PHP";
            }
        ?>
    </body>
</html>

05 Bloques de código

5.1 Sintaxis básica

  • Las variables son sensibles a mayúsculas/minúsculas, pero no las palabras clave.
  • Los espacios en blanco dentro del código embebido no tienen ningún efecto.
  • El final de instrucción se indica con ;.
  • Los scripts embebidos pueden situarse en cualquier parte del código HTML.
  • El número de scripts es indefinido.
  • Cuando se ejecuta un código embebido, el script se sustituye por el resultado de dicha ejecución, incluidas las etiquetas de inicio y fin.
<!DOCTYPE html>
<html>
    <?php
        $salida="contenido php";
    ?>
    <head>
        <meta charset="UTF-8">
        <title> <?php  echo $salida;  ?>
        </title>
    </head>
    <body>
        <h1>Otro ejemplo</h1>
        <h2>
        <?php
            echo $salida;
        ?>
        </h2>
    </body>
</html>

06 Variables y tipos de datos

El tipo de una variable no se suele especificar:

$miVariable = 7;

Se decide en tiempo de ejecución en función del contexto y puede variar:

$miVariable = 7;
$miVariable = "cambio de tipo";

Reglas para nombrar variables en PHP

  • El nombre debe comenzar con una letra o con un guión bajo ("_").
  • El nombre únicamente puede contener caracteres alfanuméricos y guiones bajos.
  • El nombre de una variable no debe contener espacios en blanco. Para nombres compuestos se usa guión bajo ($mi_variable) o primera letra en mayúsculas ($miVariable).

Tipos de datos

  • boolean: valores true y false. Cualquier número entero se considera true salvo el 0, que es false.
  • int: cualquier número sin decimales. Se pueden representar en formato decimal, octal (comenzando por 0) o hexadecimal (comenzando por 0x).
  • float: cualquier número con decimales. También en notación científica.
  • string: conjuntos de caracteres delimitados por comillas simples o dobles.
  • null: tipo especial para indicar que la variable no tiene valor.
Ejercicio 1: Comprueba el resultado visualizando por pantalla: $miBoolean = false; $miEntero= 0x2A; $miReal=7.3e-1; $miCadena="texto"; $miVariable=null;

Ejercicio 2: ¿De qué tipo es la variable $resultado? $miEntero=3; $miReal=2.3; $resultado=$miEntero+$miReal;

6.1 Cadenas de texto

  • Se definen tanto con comillas simples como dobles.
  • Cuando se pone una variable dentro de comillas dobles, PHP la procesa y sustituye por su valor.
<?php
    $modulo="DWES";
    echo "<p> Módulo: $modulo </p>";
?>

Para que PHP distinga correctamente el texto de la variable, a veces es necesario encerrarla entre llaves:

<?php
    echo "<p> Módulo: ${modulo} </p>";
?>

Concatenación de cadenas

  • Concatenación con punto (.).
  • Operador de asignación y concatenación (.=): concatena al argumento del lado izquierdo la cadena del lado derecho.
<?php
    $a="Módulo ";
    $b= $a."DWES";
    // ahora $b contiene "Módulo DWES"
    $a .="DWES";
    // ahora $a también contiene "Módulo DWES"
?>

07 Ámbito de las variables

  • Se pueden utilizar en cualquier lugar del programa.
  • Si la variable no existe, se reserva espacio en memoria.
  • Si una variable se define dentro de una función, es una variable local a la función.
  • Si aparece fuera de la función, se considera distinta a la definida dentro.
  • Si dentro de una función se quiere usar una variable definida fuera, hay que usar la palabra global.
  • Si se quiere mantener el valor de una variable definida dentro de una función al salir de ésta, se debe definir como static.

08 Operadores del lenguaje. Tipos

  • Operadores aritméticos: +, -, *, /, %, ++, --
  • Operador de asignación: =
  • Operadores de comparación: ==, !=, <, >, <=, >=
  • Operadores lógicos: and (&&), or (||), !, xor
  • Operadores de cadena: concatenación . (punto), asignación con concatenación .=

8.1 Precedencia de operadores (de menor a mayor)

  1. ++, -- (operadores unarios)
  2. *, /, %
  3. +, -
  4. <, <=, >, >=
  5. ==, !=
  6. &&
  7. ||
  8. and
  9. or

09 Funciones relacionadas con los tipos de datos

Funciones para comprobar y establecer el tipo de datos de una variable:

gettype(): obtiene el tipo de variable.

gettype($variable);

settype(): convierte una variable al tipo indicado por parámetro.

settype($variable, "float");

Funciones para comprobar si es de un tipo concreto:

  • is_array(), is_bool(), is_float(), is_integer()...
  • isset(): indica si una variable está definida y no es null. 
    isset($variable);
  • unset(): destruye una variable. 
    unset($variable);

Funciones para Fechas

No hay un tipo específico para fechas. La información se almacena como número entero y existen funciones en PHP para trabajar con ellas.

date(): permite obtener una cadena de texto a partir de una fecha y hora con el formato elegido.

// date(string $formato [, int $fechahora]);
$fechaActual = date('Y-m-d');
echo $fechaActual; // Imprime: 2024-09-29

Si no se indica el segundo parámetro, se utiliza la hora actual.

La clase DateTime es una de las más utilizadas para trabajar con fechas y horas:

// Crear un objeto DateTime a partir de una cadena de fecha
$fecha = new DateTime('2024-10-29');
// Añadir un día a la fecha
$fecha->modify('+1 day');
// Establecer la zona horaria a Madrid
$fecha->setTimezone(new DateTimeZone('Europe/Madrid'));
// Imprimir la fecha y hora formateada
echo $fecha->format('Y-m-d H:i:s');

Diferencia entre dos fechas usando diff():

$fecha1 = new DateTime('2024-06-15');
$fecha2 = new DateTime('2024-09-22');
$diferencia = $fecha1->diff($fecha2);
echo $diferencia->format('%a días'); // Imprime: 99 días

La clase IntlDateFormatter proporciona una forma más avanzada y flexible de formatear fechas (API de internacionalización Intl, maneja diferentes formatos para diferentes idiomas y regiones):

$fecha = new DateTime('2024-09-05');
$formateador = new IntlDateFormatter('es_ES');
$formateador->setPattern("MMMM");
echo $formateador->format($fecha);
echo "<br>";

$formateador->setPattern("EEEE d 'de' MMMM");
echo $formateador->format($fecha);
echo "<br>";

$formateador = new IntlDateFormatter('es_ES', IntlDateFormatter::FULL, IntlDateFormatter::NONE);
echo $formateador->format($fecha);
echo "<br>";

$formateador = new IntlDateFormatter('es_ES', IntlDateFormatter::LONG, IntlDateFormatter::NONE);
echo $formateador->format($fecha);
echo "<br>";

$formateador = new IntlDateFormatter('es_ES', IntlDateFormatter::MEDIUM, IntlDateFormatter::NONE);
echo $formateador->format($fecha);
echo "<br>";

$formateador = new IntlDateFormatter('es_ES', IntlDateFormatter::SHORT, IntlDateFormatter::NONE);
echo $formateador->format($fecha);
echo "<br>";

10 Variables especiales en PHP

PHP incluye variables internas predefinidas que pueden usarse desde cualquier ámbito. Se denominan superglobales. Cada una es un array que contiene un conjunto de valores.

Variable Descripción
$_SERVER Contiene información sobre el entorno del servidor web y de ejecución.
$_GET Contiene las variables pasadas al guión actual mediante el método GET (parámetros en la URL).
$_POST Contiene las variables pasadas mediante HTTP POST.
$_COOKIE Contiene las variables pasadas mediante Cookies HTTP.
$_REQUEST Junta en uno solo el contenido de $_GET, $_POST y $_COOKIE.
$_FILES Contiene los ficheros que se puedan haber subido al servidor utilizando el método POST.
$_SESSION Contiene las variables de sesión disponibles para el guión actual.
