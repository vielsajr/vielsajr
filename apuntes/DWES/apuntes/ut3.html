PHP — Estructuras, Arrays y Formularios

Sentencias condicionales, bucles, funciones, arrays, métodos GET/POST y procesamiento de formularios en PHP.

01 Tomas de decisión

Denominadas sentencias condicionales.

if / elseif / else

Definir una expresión para ejecutar o no la sentencia o conjunto de sentencias siguientes:

<?php
    if ($a<$b)
        echo "a es menor que b";
    elseif ($a>$b)
        echo "a es mayor que b";
    else
        echo "a es igual a b";
?>

No es necesario poner {} cuando solo se ejecuta una sentencia en cada caso.

switch

Similar a enlazar varias sentencias if comparando una misma variable con diferentes valores:

<?php
    switch ($a){
        case 0:
            echo " a vale 0";
            break;
        case 1:
            echo " a vale 1";
            break;
        default:
            echo "a no vale 0 ni 1";
    }
?>

Si se omite break, la ejecución continúa con el siguiente case.

02 Bucles

Son sentencias repetitivas: while, do...while, for.

while

Define un bucle que se ejecuta mientras se cumpla una expresión. La expresión se evalúa antes de comenzar cada ejecución:

<?php
    $a=1;
    while ($a <8)
        $a+=3;
    echo $a; // el valor obtenido es 10
?>

No es necesario poner {} cuando solo se ejecuta una sentencia.

do ... while

La expresión se evalúa al final, por lo que la sentencia se ejecuta al menos una vez:

<?php
    $a = 15;
    do {
        $a -= 3;
    } while ($a > 10);
    echo $a; // imprime 9
?>

for

Compuesto por tres expresiones:

for(expr1; expr2; expr3){
    sentencia o conjunto de sentencias
}
  • expr1: se ejecuta una vez al comienzo del bucle.
  • expr2: se evalúa para saber si se debe ejecutar la/as sentencia/as.
  • expr3: se ejecuta tras ejecutar todas las sentencias del bucle.
<?php
    for ($a=5; $a<10; $a+=3){
        echo $a; // se muestran los valores 5 y 8
        echo "<br/>";
    }
?>

03 Funciones

  • Permiten asociar una etiqueta (el nombre de la función) con un bloque de código a ejecutar.
  • Ayudan a estructurar mejor el código.
  • Permiten crear variables locales no visibles fuera de la función.

3.1 Inclusión de funciones en ficheros externos

Formas de incorporar ficheros externos:

  • include: incluye el fichero; si no se encuentra, da un aviso y continúa la ejecución.
  • include_once: evita incluir más de una vez el mismo fichero.
  • require: si el fichero no se encuentra, detiene la ejecución.
  • require_once: combinación de las dos anteriores.
<?php
   include 'funciones.inc.php';
   echo fecha();
?>

3.2 Creación y ejecución de funciones

Para crear funciones se usa la palabra function:

<?php
    function saludo(){
        return "Hola, esto es una función";
    }
    echo saludo();
?>

3.3 Argumentos en las funciones

Es mejor usar argumentos o parámetros. Las funciones pueden devolver un valor con return:

<?php
    function precio_con_iva($precio){
        return $precio*1.21;
    }
    $precio=10;
    $precio_iva=precio_con_iva($precio);
    echo "el precio con IVA es ".$precio_iva;
?>

Puedes indicar valores por defecto para los argumentos:

<?php
    function precio_con_iva($precio, $iva=0.21){
        return $precio*(1+$iva);
    }
?>

Para pasar argumentos por referencia (que los cambios se reflejen fuera), añade & antes del nombre:

<?php
    function precio_con_iva(&$precio, $iva=0.21){
        return $precio*(1+$iva);
    }
?>

Para acceder a una variable global dentro de una función, usa la palabra clave global. Su uso NO es una buena práctica.

<?php
   function precio_con_iva(){
        global $precio;
        $precio_iva=$precio*1.21;
        echo "el precio con IVA es ".$precio_iva;
   }
   $precio=10;
   precio_con_iva();
?>

No es necesario definir las funciones antes de usarlas, excepto cuando están definidas condicionalmente:

<?php
    $iva=true;
    $precio=10;
    precio_con_iva(); // Da error, pues aquí aún no está definida
    if ($iva){
        function precio_con_iva(){
            global $precio;
            echo "el precio con IVA es ".($precio*1.21);
        }
    }
    precio_con_iva(); // aquí ya no da error
?>

04 Tipos de datos compuestos

Un tipo de datos compuesto permite almacenar más de un valor. En PHP se pueden utilizar dos tipos: el array y el objeto.

05 Arrays y cadenas

Un array permite almacenar varios valores referenciados por una clave (numérica o asociativa):

// Array numérico
$modulos1 = [0=>"Programación", 1=>"Base de datos", ..., 9=>"Desarrollo web en entorno servidor"];

// Array asociativo
$modulos2 = ["PR"=>"Programación", "BD"=>"Base de datos", ..., "DWES"=>"DWES"];
  • print_r muestra todo el contenido del array.
  • Para referenciar elementos: $modulos1[9]; o $modulos2["DWES"];

Se pueden crear arrays multidimensionales:

$ciclos = [
    "DAW" => ["PR"=>"Programación", ..., "DWES"=>"DWES"],
    "DAM" => ["PR"=>"Programación", ..., "AD"=>"Acceso a datos"]
];
// Acceso: $ciclos["DAW"]["DWES"];

No hay que indicar el tamaño del array. La clave se puede omitir (se asigna automáticamente):

$modulos1[] = "Programación";
$modulos1[] = "Base de datos";
$modulos1[] = "DWES";

5.1 Recorrer un array

Las cadenas de texto se pueden tratar como arrays donde cada posición almacena una letra ($modulo[3] == "a").

Para recorrer un array se usa el bucle foreach:

// Solo los elementos:
foreach ($modulos1 as $modulo)
    echo $modulo . "<br/>";

// Elementos y claves simultáneamente:
foreach ($modulos2 as $codigo => $modulo)
    echo "El código del módulo ".$modulo." es ".$codigo."<br/";

06 Recuperación de información del cliente Web

6.1 Métodos GET y POST

  • GET: el método más usado, pero NO es recomendable para formularios. Pide al servidor que devuelva la información identificada en la URI.
  • POST: se usa para enviar información a un servidor. Se utiliza básicamente en formularios.

La principal diferencia radica en la codificación de la información. Es conveniente usar GET para la recuperación y POST para el envío.

6.2 Método GET

Utiliza la dirección URL. Detrás de la URL el símbolo ? indica el comienzo de las variables, separadas por &:

Ejemplo: http://www.example.org/file/example1.php?v1=0&v2=3

6.3 Método POST

La información va codificada en el cuerpo de la petición HTTP y por tanto viaja oculta.

07 Formularios

Son la forma de hacer llegar los datos a una aplicación web. Van encerrados en <form>...</form>. Dentro se pueden incluir elementos como <input>, <select>, <textarea>, <button>.

  • Los elementos necesitan el atributo name para enviarse al servidor.
  • action: indica la página a la que se enviarán los datos.
  • method: get (datos en la URI con ?) o post (datos en el cuerpo HTTP).

Ejemplo con GET:

<form action="ejemplo1.php" method="get">
    <label for="nombre">Introduzca su nombre:</label>
    <input type="text" id="nombre" name="nombre"><br/>
    <label for="apellido">Introduzca sus apellidos:</label>
    <input type="text" id="apellido" name="apellidos"><br/>
    <input type="submit" name="enviar" value="Enviar">
</form>

Ejemplo con POST:

<form action="ejemplo1.php" method="post">
    <label for="nombre">Introduzca su nombre:</label>
    <input type="text" id="nombre" name="nombre"><br/>
    <label for="apellido">Introduzca sus apellidos:</label>
    <input type="text" id="apellido" name="apellidos"><br/>
    <input type="submit" name="enviar" value="Enviar">
</form>

08 Procesamiento de la información

8.1 Con GET

La variable $_GET almacena todas las variables pasadas con GET. Es un array indexado por el nombre del elemento del formulario:

$_GET['nombre'];
$_GET['apellidos'];

// Mostrar todo el array:
<?php print_r($_GET); ?>

8.2 Con POST

La variable $_POST almacena las variables pasadas con POST, también como array indexado por el nombre del elemento:

$_POST['nombre'];
$_POST['apellidos'];

$_REQUEST contiene tanto el contenido de $_GET como $_POST.

8.3 Validación de datos

Siempre que sea posible, validar los datos en el navegador antes de enviarlos, usando código JavaScript. Si hay datos que requieren validación en el servidor (p.ej. comprobar datos en la BD), se hace con PHP en la página del action:

<html>
    <body>
        <?php
            if (isset($_POST['enviar'])) {
                $nombre = $_POST['nombre'];
                $modulos = $_POST['modulos'];
                print "Nombre: ".$nombre."<br />";
                foreach ($modulos as $modulo) { print "Modulo: ".$modulo."<br />"; }
            }
            else {
        ?>
        <form name="input" action="" method="post">
            <label for="nombre">Nombre del alumno: </label>
            <input type="text" name="nombre" id="nombre" /><br />
            <p>Módulos que cursa:</p>
            <input type="checkbox" name="modulos[]" value="DWES" /> DWES<br />
            <input type="checkbox" name="modulos[]" value="DWEC" /> DWEC<br />
            <input type="submit" name="enviar" value="Enviar" />
        </form>
        <?php } ?>
    </body>
</html>

En el atributo action del formulario también se puede poner echo $_SERVER['PHP_SELF']; para que el formulario se envíe a sí mismo.
