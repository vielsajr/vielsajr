Laravel — Framework MVC

Patrón MVC, instalación y estructura de Laravel, rutas, controladores, vistas Blade, base de datos con Eloquent ORM, middleware y autenticación de usuarios.

01 Patrón MVC

El patrón Modelo–Vista–Controlador (MVC) divide el código en tres partes con funciones diferenciadas:

  • Modelo: maneja los datos de la aplicación. Si hay un SGBD, se encarga de almacenar y recuperar la información.
  • Vista: responsable de la interacción con el usuario. Genera el interfaz HTML según la información del modelo.
  • Controlador: decide qué hacer en función de las acciones del usuario, interactúa con el modelo y envía instrucciones a la vista.

Funcionamiento MVC

  1. El usuario envía una petición al controlador vía URL.
  2. El controlador solicita al modelo los datos.
  3. El modelo devuelve los datos.
  4. El controlador selecciona una vista.
  5. Se devuelve la vista al controlador.
  6. El controlador devuelve la vista con los datos del modelo.

La arquitectura MVC separa la lógica de negocio (modelo) de la presentación (vista), facilitando el mantenimiento. El controlador aísla al modelo y la vista de los detalles del protocolo HTTP.

02 Laravel

Laravel es un framework de código abierto para PHP con sintaxis simple y elegante. Creado en 2011 por Taylor Otwell, inspirado en Ruby on Rails y Symfony. Diseñado bajo el patrón MVC, incluye el ORM Eloquent y el motor de plantillas Blade.

Instalación

Requisitos previos: servidor web (Apache), PHP y un gestor de BD (MySQL). Luego instalar Composer:

# Instalar Laravel globalmente
composer global require laravel/installer

# Actualizar el instalador
composer global update laravel/installer

# Comprobar versión
laravel -v

# Crear un nuevo proyecto
laravel new prueba-laravel

# Alternativa en un solo paso
composer create-project laravel/laravel prueba-laravel

Desde la versión 11, Laravel usa SQLite por defecto. Configurar permisos:

chmod -R 777 storage bootstrap/cache
chmod 777 database/database.sqlite
sudo apt-get install php8.x-sqlite3

Node.js (NVM)

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc

nvm ls-remote          # Ver versiones remotas
nvm install v20.18.0   # Instalar versión
nvm use v20.18.0       # Usar versión
node -v && npm -v      # Comprobar versiones

04 Funcionamiento básico

  1. Todas las peticiones entran por public/index.php, que comprueba el fichero de rutas routes/web.php.
  2. Se llama al método del controlador asignado a esa ruta.
  3. Se accede a la base de datos mediante los modelos (si es necesario).
  4. Los datos se preparan para pasarlos a la vista.
  5. Se muestra la vista al usuario.

05 Artisan

Laravel incluye Artisan, una interfaz de línea de comandos (CLI) para realizar múltiples tareas de desarrollo.

php artisan list              # Ver todas las opciones
php artisan route:list        # Listar rutas definidas
php artisan serve             # Servidor interno (localhost:8000)
php artisan make:controller TaskController  # Crear controlador

Mediante la opción make se pueden generar controladores, modelos, filtros y otros componentes como plantillas.

06 Rutas

Las rutas se definen en routes/web.php. Cualquier ruta no definida devuelve error 404. Construyen URLs amigables.

Métodos básicos

// Ruta GET básica
Route::get('/', function() {
  return view('welcome');
});

// Ruta POST
Route::post('foo/bar', function() {
  return 'Hola mundo';
});

// GET y POST juntos
Route::match(['GET','POST'], '/', function() {
  return 'Hola mundo';
});

// Cualquier tipo de petición
Route::any('/', function() {
  return 'Hola mundo';
});

Parámetros en rutas

// Parámetro obligatorio
Route::get('user/{id}', function($id) {
  return 'User ' . $id;
});

// Parámetro opcional
Route::get('user/{name?}', function($name = 'ivan') {
  return $name;
});

// Con expresión regular
Route::get('user/{name?}', function($name) {
  return $name;
})->where('name', '[A-Za-z]+');

Named routes (rutas con nombre)

Route::get('clientes', function() {
  return "listado";
})->name('ruta_clientes');

07 Controladores

Los controladores agrupan el código para responder a peticiones HTTP. Son el intermediario entre la vista y el modelo. Se almacenan en App/Http/Controllers con sufijo Controller.

<?php
namespace App\Http\Controllers;
use Illuminate\Http\Request;

class HomeController extends Controller
{
    public function __invoke(Request $request)
    {
       return view('home');
    }
}

Asociar a una ruta:

Route::get('/', HomeController::class)->name('home');

Crear controladores con Artisan

# Controlador básico
php artisan make:controller EjemploController

# Con método __invoke (opción -i)
php artisan make:controller EjemploController -i

# Controlador de recursos con -r (métodos CRUD predefinidos)
php artisan make:controller ArticuloController -r

# En subcarpeta
php artisan make:controller Fotos/AdminController

Métodos de un controlador de recursos

MétodoDescripción
indexMuestra un listado de los elementos
createMuestra el formulario para crear nuevos elementos
storeAlmacena en BD el recurso creado con el formulario
showMuestra los datos de un recurso específico (por id)
editMuestra el formulario para editar un recurso
updateActualiza en BD el recurso editado
destroyElimina un recurso por su identificador

Generar URL a una acción

// En web.php
Route::get('foo', [FooController::class,'method'])->name("foo.method");

// En la plantilla Blade
<a href="{{ route('foo.method') }}">¡Pulsa aquí!</a>

08 Vistas

Las vistas presentan el resultado de forma visual al usuario. Se almacenan en resources/views como ficheros PHP. No realizan consultas; solo reciben datos y los muestran en HTML.

Pasar variables a las vistas

// Con método with()
return view('inicio')->with(['nombre'=>$nombre,'apellidos'=>$apellidos]);

// Como segundo parámetro array
return view('inicio', ['nombre'=>$nombre,'apellidos'=>$apellidos]);

// Con compact() — la más usada
return view('inicio', compact('nombre','apellidos'));

Acceder en la vista con PHP o con Blade:

<!-- PHP clásico -->
<p>Bienvenido <?php echo $nombre.",".$apellidos ?></p>

<!-- Sintaxis Blade -->
<p>Bienvenido {{$nombre}}, {{$apellidos}}</p>

Organización en subcarpetas

Notación tipo dot para vistas en subcarpetas:

// Vista en resources/views/user/register.php
Route::get('register', function() {
  return view('user.register');
});

09 Motor de plantillas Blade

Laravel usa Blade para plantillas en vistas. Ficheros con extensión .blade.php. El código empieza por @ o {{ }}. No añade sobrecarga porque las vistas son preprocesadas y cacheadas.

Mostrar datos

Hola {{$name}}
La hora actual es {{time()}}

{{-- Comentario Blade (no aparece en HTML) --}}

{{-- Dato con valor por defecto --}}
{{ $name or 'Valor por defecto' }}

Estructuras de control

@if( count($users) === 1 )
  ¡Solo hay un usuario!
@elseif (count($users) > 1)
  ¡Hay muchos usuarios!
@else
  ¡No hay ningún usuario!
@endif

@for ($i = 0; $i < 10; $i++)
  El valor actual es {{ $i }}
@endfor

@foreach ($users as $user)
  <p>Usuario {{ $user->name }} — ID: {{ $user->id }}</p>
@endforeach

@forelse ($elementos as $elemento)
  <li>{{$elemento}}</li>
@empty
  <li>No hay elementos</li>
@endforelse

Enlaces a otras rutas

<a href="{{route('ruta_contacto')}}">contacto</a>
<a href="{{url('/contacto')}}">contacto</a>

Plantillas (Layouts)

Crear resources/views/layouts/plantilla.blade.php:

<!DOCTYPE html>
<html lang="es">
<head>
    <title>@yield('titulo')</title>
</head>
<body>
    @include('layouts.partials.header')
    @yield('contenido')
    @include('layouts.partials.footer')
</body>
</html>

Vista hija que usa la plantilla:

@extends('layouts.plantilla')
@section('titulo','Inicio')
@section('contenido')
    <h1>Bienvenido a la página principal</h1>
@endsection

Incluir una vista dentro de otra:

@include('view_name')
@include('view_name', ['some' => 'data'])

11 Formularios

<form action="{{route('cursos.insertar')}}" method="POST">
    @csrf
    <input type="text" name="nombre" value="{{ old('nombre') }}">
    @error('nombre')
        <div class="text-danger">{{ $message }}</div>

Protección CSRF

La directiva @csrf añade un campo oculto para proteger contra ataques CSRF (Cross-site request forgery). Olvidarlo provoca error 419.

Validación de formularios

public function insertar(Request $request) {
    $request->validate(
      ['nombre' => 'required|min:4',
       'apellidos' => 'required|min:4'],
      ['nombre.required' => 'el nombre es obligatorio',
       'apellidos.required' => 'los apellidos son obligatorios']
    );
}

Mostrar todos los errores:

@if ($errors->any())
    <ul>
        @foreach ($errors->all() as $error)
            <li>{{ $error }}</li>
        @endforeach
    </ul>
@endif

Form Request (validaciones complejas)

php artisan make:request CrearClienteRequest

Se almacena en app/Http/Requests. Contiene los métodos: authorize (booleano de autorización), rules (reglas de validación), messages (mensajes de error personalizados) y attributes (nombres personalizados de atributos).

// En el controlador, usar CrearClienteRequest en lugar de Request
public function InsertarConValidacion(CrearClienteRequest $request) {
    // Si llegamos aquí, el formulario es válido
}

Migraciones: Schema Builder

Las migraciones definen y crean tablas desde código, manteniendo un historial de cambios.

# Ejecutar migraciones
php artisan migrate

# Crear migración para nueva tabla
php artisan make:migration create_users_table

# Migración que modifica tabla existente
php artisan make:migration add_votes_to_user_table --table=users

# Deshacer última migración
php artisan migrate:rollback

# Deshacer todas las migraciones
php artisan migrate:reset

# Rehacer todas las migraciones (desarrollo)
php artisan migrate:fresh

# Ver estado de migraciones
php artisan migrate:status

Estructura de una migración (métodos up y down):

Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('email')->unique();
    $table->timestamp('email_verified_at')->nullable();
    $table->string('password');
    $table->rememberToken();
    $table->timestamps();
});

// En el método down:
Schema::dropIfExists('users');

Índices y claves ajenas

$table->primary('id');
$table->unique('email');
$table->index('state');

// Clave ajena
$table->foreignId('user_id');
$table->foreign('user_id')->references('id')->on('users');
$table->foreign('user_id')->references('id')->on('users')->onDelete('cascade');

// Eliminar clave ajena (en método down)
$table->dropForeign('posts_user_id_foreign');

Eloquent ORM

Laravel incluye Eloquent ORM para mapeo objeto-relacional. Crear modelo con Artisan:

php artisan make:model User

Eloquent pluraliza automáticamente el nombre del modelo para buscar la tabla. Si el nombre es distinto, usar $table. La clave primaria por defecto es id.

class User extends Model
{
    protected $table = 'my_users';
    protected $primaryKey = 'my_id';
    public $timestamps = false;
}

Consultar datos

$users = User::all();           // Todos los registros
$user = User::find(1);          // Por id
$user = User::findOrFail(1);    // Lanza excepción si no existe

// Con condiciones
$users = User::where('votes', '>', 100)->take(10)->get();
$user  = User::where('votes', '>', 100)->first();

// Agregados
$count = User::where('votes', '>', 100)->count();
$max   = Orders::max('price');
$total = User::sum('votes');

Insertar, actualizar y borrar

// Insertar
$user = new User();
$user->name = "Juan";
$user->save();
$insertedId = $user->id;

// Actualizar
$user = User::find(1);
$user->email = "juan@gmail.com";
$user->save();

// Borrar
$user = User::find(1);
$user->delete();
// Borrar conjunto
User::where('votes', '>', 100)->delete();

Relaciones con Eloquent ORM

Uno a uno — hasOne / belongsTo:

// En modelo Libro
public function portada() {
    return $this->hasOne(Portada::class);
}

// En modelo Portada (relación inversa)
public function libro() {
    return $this->belongsTo(Libro::class);
}

// Uso
$portada = Libro::findOrFail($id)->portada;
$libro   = Portada::findOrFail($idportada)->libro;

Uno a muchos — hasMany / belongsTo:

// En modelo Autor
public function libros() {
    return $this->hasMany(Libro::class);
}

// En modelo Libro (relación inversa)
public function autor() {
    return $this->belongsTo(Autor::class);
}

// Uso
$libros      = Autor::findOrFail($id)->libros;
$nombreAutor = Libro::findOrFail($id)->autor->nombre;

Muchos a muchos — belongsToMany (requiere tabla intermedia):

// En modelo Libro
public function bibliotecas() {
    return $this->belongsToMany(Biblioteca::class);
}

// En modelo Biblioteca
public function libros() {
    return $this->belongsToMany(Libro::class);
}

// Uso
$bibliotecas = Libro::findOrFail($id)->bibliotecas;

15 Middleware o filtros

Los Middleware filtran las peticiones HTTP. Se almacenan en app/Http/Middleware. Pueden permitir, dar error o redirigir.

# Crear middleware
php artisan make:middleware MyMiddleware
class MyMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->input('age') < 18) {
            return redirect('home');
        }
        return $next($request); // Continuar petición
        // abort(403, 'Unauthorized action.');
    }
}

Registrar y usar middleware

Registrar en bootstrap/app.php:

// Middleware global
->withMiddleware(function (Middleware $middleware) {
    $middleware->append(MyMiddleware::class);
})

// Con alias
->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'es_mayor_de_edad' => MyMiddleware::class
    ]);
})

Proteger rutas con el middleware auth:

// Ruta protegida
Route::get('admin/catalog', function() { ... })->middleware('auth');

// Acción de controlador protegida
Route::get('profile', [ProfileController::class,'show'])->middleware('auth');

// Middleware propio
Route::get('/', function() { ... })->middleware('es_mayor_de_edad');

// Múltiples middleware
Route::get('/', function() { ... })->middleware(['first', 'second']);

16 Control de usuarios

Laravel incluye por defecto: configuración en config/auth.php, migración de la tabla users y el modelo User.php en app/Models.

Laravel Breeze

Implementación mínima de autenticación: inicio de sesión, registro, restablecimiento de contraseña, verificación de email y confirmación de contraseña.

composer require laravel/breeze --dev
php artisan breeze:install   # Elegir "Blade with Alpine"
php artisan migrate
npm install
npm run dev

Genera rutas en routes/web.php y vistas en resources/views/auth.

Autenticación y sesión

// Acceder a los datos del usuario autenticado
use Illuminate\Support\Facades\Auth;
$user  = Auth::user();
$email = Auth::user()->email;

// Cerrar sesión
Auth::logout();

// Comprobar si está autenticado
if (Auth::check()) {
    // El usuario está correctamente autenticado
}

// Registro manual (cifrar contraseña con bcrypt)
$user->password = bcrypt($request->password);
$user->save();

Laravel Jetstream

Aumenta la funcionalidad de Breeze: verificación por email, autenticación de dos pasos, administrador de sesiones, soporte de API, gestión de equipos.

npm install && npm run dev && npm run build

Librería laravel-permission (Spatie)

Gestión de roles y permisos en Laravel:

composer require spatie/laravel-permission
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"
php artisan config:clear
php artisan migrate

Añadir trait HasRoles al modelo User:

use Spatie\Permission\Traits\HasRoles;
class User extends Authenticatable {
    use HasRoles;
}

// Asignar rol
$user->assignRole('admin');

// Crear rol y permiso
$role   = Role::create(['name' => 'gestor']);
$permiso = Permission::create(['name' => 'editar articulos']);
$role->givePermissionTo($permiso);

// Verificar
$user->hasRole('admin');
$user->can('editar articulos');

// Proteger rutas por rol
Route::middleware(['role:admin'])->group(function () {
    // Solo accesible para 'admin'
});

Registrar middleware en bootstrap/app.php:

$middleware->alias([
    'role' => \Spatie\Permission\Middleware\RoleMiddleware::class
]);
