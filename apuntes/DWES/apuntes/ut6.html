01 Gestión de sesiones

El término sesión hace referencia al conjunto de información relativa a un usuario concreto.

Ejemplos de información de sesión:

  • Nombre del usuario.
  • Artículos de la lista de la compra de una tienda online.

Cada usuario distinto de un sitio web tiene su propia información de sesión. Para distinguir una sesión de otra se usan los identificadores de sesión (SID).

Un SID es un atributo que se asigna a cada uno de los visitantes de un sitio web y lo identifica.

¿Dónde se almacena el SID?

Existen dos maneras de mantener el SID entre las páginas de un sitio web:

  • Utilizando cookies.
  • Propagando el SID en la URL: el SID se añade como una parte más de la URL: 
    http://www.mitienda.com/listado.php&PHPSESSID=34534fg4ffg34ty

PHP y el manejo automático de sesiones

  • Cuando un usuario visita un sitio web, no es necesario programar un procedimiento para ver si existe un SID previo y cargar los datos asociados.
  • Tampoco hay que usar setcookie si se quiere almacenar los SID en cookies, ni ir pasando el SID entre páginas. PHP lo hace automáticamente.
  • Por defecto, PHP incluye soporte de sesiones incorporado.

Configuración en php.ini

Antes de utilizar sesiones debes configurar correctamente PHP usando las siguientes directivas en php.ini:

DirectivaSignificado
session.use_cookies Indica si se deben usar cookies (1) o propagación en la URL (0) para almacenar el SID.
session.use_only_cookies Se debe activar (1) cuando se usan cookies para almacenar los SID, y además no se quiere que se reconozcan los SID que se puedan pasar como parte de la URL (puede usarse para usurpar el identificador de otro usuario).
session.save_handler Indica a PHP cómo almacenar los datos de la sesión. Opciones: en ficheros (files), en memoria (mm), en base de datos SQLite (sqlite) o con funciones definidas por el programador (user). El valor por defecto (files) funcionará sin problemas en la mayoría de los casos.
session.name Determina el nombre de la cookie para guardar el SID. Su valor por defecto es PHPSESSID.
session.auto_start Su valor por defecto es 0; deberás usar session_start para gestionar el inicio de sesiones. Si usas sesiones en el sitio, puede ser buena idea cambiarlo a 1 para que PHP active las sesiones automáticamente.
session.cookie_lifetime Si se usa la URL para propagar el SID, éste se pierde al cerrar el navegador. Con cookies, el SID se mantiene mientras no se destruya la cookie. En su valor por defecto (0), las cookies se destruyen al cerrar el navegador. Para mantener el SID más tiempo, indicar ese tiempo en segundos.
session.gc_maxlifetime Tiempo en segundos para mantener activa la sesión aunque no haya actividad por parte del usuario. Su valor por defecto es 1440 (24 minutos).

Inicio de sesión

El inicio de una sesión puede tener lugar de dos formas:

  • Si se ha activado session.auto_start, la sesión comenzará automáticamente cuando el usuario se conecte.
  • Si no, hay que ejecutar la función session_start() para indicar a PHP que inicie una nueva sesión o reanude la anterior. Devuelve false si no puede iniciar o restaurar la sesión.

Variable superglobal $_SESSION

Mientras la sesión permanece abierta, puedes usar $_SESSION para añadir o acceder a la información almacenada:

var_dump($_SESSION);

Eliminar información de sesión

  • session_unset(): elimina las variables almacenadas en la sesión actual, pero no elimina la información del dispositivo de almacenamiento. Equivale a hacer $_SESSION = array();
  • session_destroy(): elimina completamente la información de la sesión del dispositivo de almacenamiento.

02 Ejercicio grupal

El trabajo se realizará en grupo. La idea es construir una aplicación web que sea una red de valoraciones/recomendaciones. Los usuarios podrán valorar elementos como podcasts, películas, libros, restaurantes, videojuegos, series, música, actividades, gadgets, etc.

La base de datos debe incluir al menos las tablas: usuarios, elementos y valoraciones.

Se debe utilizar POO y sesiones de usuario.

2.1 Registro de usuarios

Crear una página registro.php para que se registren usuarios con sus datos personales.

2.2 Login

Crear una página login.php con, al menos, un formulario con dos campos:

  • Un campo de tipo text para el usuario.
  • Un campo de tipo password para la contraseña.

Al pulsar el botón Enviar, el formulario se enviará a esta misma página, donde se compararán las credenciales proporcionadas con las almacenadas en la base de datos.

Cuando un usuario proporciona credenciales correctas, se le redirige automáticamente a index.php.

Se deben utilizar sesiones: si los datos son correctos, se iniciará una nueva sesión y se almacenarán datos sobre el usuario que acaba de conectarse.

2.3 Elementos (index.php)

Mostrar un listado de los elementos publicados y para cada uno debe existir un botón "Valorar o Comentar".

  • Lo más sencillo es crear un formulario por cada elemento.
  • En esta página se puede mostrar el número de valoraciones realizadas o el promedio de puntuación de los elementos.
  • No se permitirá valorar si el usuario no ha iniciado sesión.
  • En la parte superior se mostrarán las valoraciones de sesión del usuario.

2.4 Valoraciones

A medida que el usuario va valorando:

  • Cada valoración se almacena en sesión.
  • Los datos de la cabecera se obtienen de la información almacenada en la sesión del usuario.
  • Además, cada valoración efectuada se almacena en base de datos.

En la parte superior habrá un formulario con un botón de desconexión que dirige a logout.php, que cerrará la sesión del usuario.

2.5 Logout

La página logout.php no muestra nada en pantalla. Su única función es:

  1. Recuperar la sesión.
  2. Eliminarla.
  3. Redirigir a index.php.
