📅 Plan de estudio — 8 semanas

Semana 1Fundamentos Java + Maven + Spring Boot: estructura, autoconfiguración, starters
Semana 2Spring MVC + REST APIs: controladores, peticiones HTTP, serialización JSON
Semana 3JPA + Hibernate: entidades, repositorios, relaciones, JPQL
Semana 4Spring Data JPA avanzado: consultas personalizadas, paginación, especificaciones
Semana 5Spring Security: autenticación, autorización, JWT, roles
Semana 6Thymeleaf + validación: plantillas, formularios, mensajes de error
Semana 7Testing: JUnit 5, Mockito, MockMvc, pruebas de integración
Semana 8Proyecto completo + despliegue + repaso + ejercicios de examen

🗂️ Módulos

MÓDULO 01
Fundamentos: Java, Maven y Spring Boot
Repaso Java moderno, Maven y pom.xml, estructura de proyecto, clase principal y application.properties.
→ MÓDULO 02
Spring Core: IoC, DI y Beans
Inversión de control, inyección de dependencias por constructor/campo/setter y anotaciones esenciales.
→ MÓDULO 03
Spring MVC: Controladores REST
Controlador REST completo, anotaciones de mapeo, parámetros y ResponseEntity con códigos HTTP.
→ MÓDULO 04
JPA & Hibernate: Entidades y Relaciones
Entidades JPA con Lombok, tipos de relaciones: OneToOne, OneToMany, ManyToOne, ManyToMany.
→ MÓDULO 05
Spring Data JPA: Repositorios y Consultas
Repositorios JPA, métodos derivados, @Query JPQL, SQL nativo, @Modifying y paginación.
→ MÓDULO 06
Validación y Manejo de Excepciones
Bean Validation con todas las anotaciones, manejador global con @RestControllerAdvice.
→ MÓDULO 07
Spring Security y JWT
SecurityFilterChain, JwtService, JwtAuthFilter, AuthController con login y registro.
→ MÓDULO 08
Thymeleaf: Plantillas del Lado Servidor
Controlador MVC, plantillas base, lista con paginación, formularios y todas las directivas th:*.
→ MÓDULO 09
Testing: JUnit 5, Mockito y MockMvc
Tests unitarios con Mockito, tests de integración de controlador con @WebMvcTest y MockMvc.
→ MÓDULO 10
Configuración, Perfiles y Despliegue
Perfiles dev/prod en application.properties, @Profile en código, Dockerfile multi-stage.
→ MÓDULO 11
Proyecto Completo: API REST de Tienda
Arquitectura en capas, patrón DTO, mapper, separación entidad/respuesta API.
→ MÓDULO 12
Cheat Sheet y Ejercicios de Examen
Referencia rápida de anotaciones, ejercicios tipo examen resueltos y checklist final.
