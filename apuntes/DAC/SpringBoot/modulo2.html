2.1 Inversión de Control y Dependency Injection

Spring gestiona la creación y ciclo de vida de los objetos (beans). En lugar de crear dependencias con new, se las pedimos a Spring. Esto facilita el testing y el desacoplamiento.
DependencyInjection.java 
// ── Formas de inyección de dependencias ────────────────────────

// 1. INYECCIÓN POR CONSTRUCTOR (RECOMENDADA) ──────────────────
@Service
public class UsuarioService {
    private final UsuarioRepository repo;   // final → inmutable
    private final EmailService emailService;

    // Si hay un solo constructor, @Autowired es opcional
    public UsuarioService(UsuarioRepository repo, EmailService emailService) {
        this.repo = repo;
        this.emailService = emailService;
    }
}

// 2. INYECCIÓN POR CAMPO (más simple pero no recomendada en producción)
@Service
public class UsuarioService {
    @Autowired
    private UsuarioRepository repo;  // Spring inyecta aquí
}

// 3. INYECCIÓN POR SETTER
@Service
public class UsuarioService {
    private UsuarioRepository repo;

    @Autowired
    public void setRepo(UsuarioRepository repo) { this.repo = repo; }
}

// ── Con Lombok (@RequiredArgsConstructor) ──────────────────────
@Service
@RequiredArgsConstructor  // genera constructor para campos 'final'
public class UsuarioService {
    private final UsuarioRepository repo;
    private final EmailService emailService;
    // Spring inyecta automáticamente por el constructor generado
}

2.2 Anotaciones esenciales de Spring

AnotaciónDescripción
@SpringBootApplicationPunto de entrada. Combina @Configuration + @ComponentScan + @EnableAutoConfiguration
@ComponentMarca una clase como Bean gestionado por Spring (genérico)
@ServiceBean de capa de servicio — lógica de negocio
@RepositoryBean de acceso a datos — traduce excepciones a DataAccessException
@ControllerBean de controlador MVC — devuelve vistas
@RestController@Controller + @ResponseBody — devuelve datos (JSON) directamente
@ConfigurationClase de configuración — equivale a un XML de Spring
@BeanMétodo que produce un Bean gestionado por Spring (dentro de @Configuration)
@AutowiredInyección de dependencia automática por tipo
@Qualifier("nombre")Seleccionar qué bean inyectar cuando hay varios del mismo tipo
@Value("${prop}")Inyectar valor de application.properties
@Profile("dev")El bean solo se crea en el perfil indicado
@Scope("prototype")Ámbito del bean: singleton (defecto), prototype, request, session
@PrimaryBean preferido cuando hay varios candidatos para una inyección
@LazyEl bean se crea cuando se usa por primera vez (no al arrancar)
