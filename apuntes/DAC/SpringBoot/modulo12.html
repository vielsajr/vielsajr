12.2 Ejercicio 1 — Entidad + Repositorio + Servicio

📝 EJERCICIO 1 — Nivel básico

Entidad + Repositorio + Servicio

Crea una entidad Producto con: id (Long, PK autogenerada), nombre (String, obligatorio, máx 100), precio (BigDecimal, positivo), stock (Integer, ≥ 0), activo (Boolean, defecto true), categoria_id (FK a Categoria). Crea el repositorio con: findByActivoTrue(), findByNombreContainingIgnoreCase(String), existsByNombre(String). Crea el servicio con: listar(), obtenerPorId(Long), crear(ProductoRequest), eliminar(Long).

ProductoSolucion.java 
// Solución: entidad Producto
@Entity @Table(name="productos")
@Data @Builder @NoArgsConstructor @AllArgsConstructor
public class Producto {
    @Id @GeneratedValue(strategy=GenerationType.IDENTITY) private Long id;
    @Column(nullable=false, length=100) private String nombre;
    @Column(nullable=false) @Positive private BigDecimal precio;
    @Column(nullable=false) @PositiveOrZero private Integer stock;
    private Boolean activo = true;
    @ManyToOne(fetch=FetchType.LAZY) @JoinColumn(name="categoria_id")
    private Categoria categoria;
}

// Repositorio
@Repository
public interface ProductoRepository extends JpaRepository<Producto, Long> {
    List<Producto> findByActivoTrue();
    List<Producto> findByNombreContainingIgnoreCase(String nombre);
    boolean existsByNombre(String nombre);
}

// Servicio (extracto)
@Service @RequiredArgsConstructor
public class ProductoServiceImpl implements ProductoService {
    private final ProductoRepository repo;

    @Transactional(readOnly=true)
    public List<Producto> listar() { return repo.findByActivoTrue(); }

    @Transactional(readOnly=true)
    public Producto obtenerPorId(Long id) {
        return repo.findById(id).orElseThrow(
            () -> new RecursoNoEncontradoException("Producto", id));
    }

    @Transactional
    public void eliminar(Long id) {
        if (!repo.existsById(id)) throw new RecursoNoEncontradoException("Producto", id);
        repo.deleteById(id);
    }
}

12.3 Ejercicio 2 — Controlador REST

📝 EJERCICIO 2 — Nivel medio

Controlador REST completo

Crea un controlador REST para el recurso /api/productos que implemente: GET /api/productos → listar todos con paginación (?page=0&size=20), GET /api/productos/{id} → obtener uno (404 si no existe), POST /api/productos → crear con validación (@Valid), DELETE /api/productos/{id} → eliminar (204 si éxito, 404 si no existe). Añade seguridad: GET público, POST y DELETE solo para ADMIN.

ProductoControllerSolucion.java 
// Solución: controlador REST
@RestController
@RequestMapping("/api/productos")
@RequiredArgsConstructor
public class ProductoController {

    private final ProductoService service;

    @GetMapping
    public ResponseEntity<Page<ProductoDTO>> listar(
            @RequestParam(defaultValue="0") int page,
            @RequestParam(defaultValue="20") int size) {
        return ResponseEntity.ok(service.listarPaginado(PageRequest.of(page, size)));
    }

    @GetMapping("/{id}")
    public ResponseEntity<ProductoDTO> obtener(@PathVariable Long id) {
        return ResponseEntity.ok(service.obtenerDTOPorId(id));
    }

    @PostMapping
    @PreAuthorize("hasRole('ADMIN')")
    public ResponseEntity<ProductoDTO> crear(@Valid @RequestBody ProductoRequest req) {
        ProductoDTO creado = service.crear(req);
        URI uri = ServletUriComponentsBuilder.fromCurrentRequest()
            .path("/{id}").buildAndExpand(creado.id()).toUri();
        return ResponseEntity.created(uri).body(creado);
    }

    @DeleteMapping("/{id}")
    @PreAuthorize("hasRole('ADMIN')")
    public ResponseEntity<Void> eliminar(@PathVariable Long id) {
        service.eliminar(id);
        return ResponseEntity.noContent().build();
    }
}
