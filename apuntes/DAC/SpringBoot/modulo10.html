10.1 Perfiles de Spring

application.properties (perfiles) 
# application.properties — configuración base
spring.profiles.active=dev  # activa el perfil 'dev' por defecto
spring.application.name=mi-app

# ── application-dev.properties — sobreescribe para desarrollo ──
spring.datasource.url=jdbc:h2:mem:testdb;DB_CLOSE_DELAY=-1
spring.jpa.hibernate.ddl-auto=create-drop
spring.jpa.show-sql=true
logging.level.com.miempresa=DEBUG

# ── application-prod.properties — sobreescribe para producción ──
spring.datasource.url=jdbc:mysql://prod-host:3306/mi_bd_prod
spring.datasource.username=${DB_USER}      # variables de entorno
spring.datasource.password=${DB_PASSWORD}
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
logging.level.root=WARN
DevDataLoader.java 
// Usar perfiles en código Java
@Configuration
@Profile("dev")
public class DevDataLoader implements CommandLineRunner {
    @Override
    public void run(String... args) {
        // Cargar datos de prueba solo en desarrollo
        System.out.println("Cargando datos de prueba...");
    }
}

// Activar perfil al arrancar:
// mvn spring-boot:run -Dspring-boot.run.profiles=prod
// java -jar app.jar --spring.profiles.active=prod
// Variable de entorno: SPRING_PROFILES_ACTIVE=prod

10.2 Dockerfile para Spring Boot

Dockerfile 
# Dockerfile — Build multi-stage para Spring Boot
FROM eclipse-temurin:21-jdk-alpine AS build
WORKDIR /app
COPY pom.xml .
COPY src ./src
RUN apk add --no-cache maven
RUN mvn clean package -DskipTests

FROM eclipse-temurin:21-jre-alpine AS production
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
EXPOSE 8080
ENV SPRING_PROFILES_ACTIVE=prod
ENTRYPOINT ["java", "-jar", "app.jar"]
El build multi-stage reduce el tamaño final de la imagen: la primera etapa compila, la segunda solo incluye el JAR y el JRE (sin Maven ni código fuente).
