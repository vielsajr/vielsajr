4.1 Entidad JPA con Lombok

Usuario.java 
// Usuario.java — Entidad JPA completa
@Entity
@Table(name = "usuarios",
       uniqueConstraints = @UniqueConstraint(columnNames = {"email"}))
@Data           // Lombok: getters, setters, toString, equals, hashCode
@Builder        // Lombok: patrón builder
@NoArgsConstructor  // Lombok: constructor vacío (requerido por JPA)
@AllArgsConstructor // Lombok: constructor con todos los campos
public class Usuario {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)  // AUTO_INCREMENT
    private Long id;

    @Column(name = "nombre", nullable = false, length = 100)
    private String nombre;

    @Column(unique = true, nullable = false)
    private String email;

    @Column(nullable = false)
    private String password;

    @Enumerated(EnumType.STRING)  // guarda 'ADMIN' no '0'
    @Column(nullable = false)
    private Rol rol = Rol.USUARIO;

    @Column(nullable = false)
    private Boolean activo = true;

    @CreationTimestamp  // Hibernate: se rellena automáticamente al crear
    @Column(updatable = false)
    private LocalDateTime creadoEn;

    @UpdateTimestamp  // Hibernate: se actualiza automáticamente
    private LocalDateTime actualizadoEn;

    // ── Relaciones ────────────────────────────────────────────
    // Un usuario TIENE MUCHOS pedidos (relación 1:N)
    @OneToMany(mappedBy = "usuario", cascade = CascadeType.ALL, fetch = FetchType.LAZY)
    @JsonIgnore  // evitar recursión infinita en JSON
    private List<Pedido> pedidos = new ArrayList<>();

    // Muchos a muchos con roles
    @ManyToMany(fetch = FetchType.EAGER)
    @JoinTable(name = "usuario_rol",
        joinColumns = @JoinColumn(name = "usuario_id"),
        inverseJoinColumns = @JoinColumn(name = "rol_id"))
    private Set<RolEntity> roles = new HashSet<>();
}

4.2 Tipos de relaciones JPA

ElementoDescripción
@OneToOneUn registro ↔ un registro. Ej: Usuario — Perfil
@OneToManyUn registro → muchos. Ej: Usuario → Pedidos. El 'mappedBy' va en el lado 'uno'.
@ManyToOneMuchos → un registro. Ej: Pedido → Usuario. La FK está en esta tabla.
@ManyToManyMuchos ↔ muchos. Crea tabla intermedia con @JoinTable.
mappedByIndica el campo del lado contrario que mapea la relación. Solo en @OneToMany y @OneToOne
@JoinColumnEspecifica el nombre de la columna FK en la tabla actual
@JoinTableDefine la tabla intermedia de una relación ManyToMany
FetchType.LAZYLa colección se carga solo cuando se accede (defecto en @OneToMany)
FetchType.EAGERLa colección se carga siempre junto con la entidad (defecto en @ManyToOne)
CascadeType.ALLLas operaciones (save, delete...) se propagan a los relacionados
orphanRemoval=trueElimina los hijos cuando se eliminan de la colección del padre
Pedido.java 
// ── Relación @ManyToOne (lado 'muchos' — tiene la FK) ─────────
@Entity
public class Pedido {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    // La FK 'usuario_id' estará en la tabla 'pedidos'
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "usuario_id", nullable = false)
    private Usuario usuario;

    @OneToMany(mappedBy = "pedido", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<LineaPedido> lineas = new ArrayList<>();

    // Método helper para mantener consistencia
    public void addLinea(LineaPedido linea) {
        lineas.add(linea);
        linea.setPedido(this);
    }
}
