8.1 Controlador MVC con Thymeleaf

VistaController.java 
// VistaController.java — Devuelve vistas HTML (no JSON)
@Controller  // NO @RestController
@RequestMapping("/usuarios")
@RequiredArgsConstructor
public class VistaController {

    private final UsuarioService service;

    @GetMapping
    public String listar(Model model,
                         @RequestParam(defaultValue="0") int page) {
        model.addAttribute("usuarios", service.listarTodos(PageRequest.of(page, 10)));
        model.addAttribute("titulo", "Lista de Usuarios");
        return "usuarios/lista";  // → templates/usuarios/lista.html
    }

    @GetMapping("/nuevo")
    public String formularioCrear(Model model) {
        model.addAttribute("usuario", new UsuarioRequest("","","",18,null,null,null));
        return "usuarios/formulario";
    }

    @PostMapping
    public String crear(@Valid @ModelAttribute("usuario") UsuarioRequest req,
                        BindingResult result,
                        RedirectAttributes redirectAttrs) {
        if (result.hasErrors()) {
            return "usuarios/formulario";  // volver al formulario con errores
        }
        service.crear(req);
        redirectAttrs.addFlashAttribute("mensaje", "Usuario creado correctamente");
        return "redirect:/usuarios";  // PRG pattern
    }
}

8.2 Plantilla base y lista con paginación

base.html 
<!-- templates/layouts/base.html — Layout base -->
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org"
      xmlns:sec="http://www.thymeleaf.org/extras/spring-security">
<head>
  <meta charset="UTF-8">
  <title th:text="${titulo} + ' | Mi App'">Mi App</title>
  <link rel="stylesheet" th:href="@{/css/app.css}">
</head>
<body>
  <nav>
    <!-- Solo visible si autenticado -->
    <span sec:authorize="isAuthenticated()">
      Hola, <span sec:authentication="name"></span>
    </span>
    <a sec:authorize="hasRole('ADMIN')" th:href="@{/admin}">Admin</a>
  </nav>

  <!-- Flash messages -->
  <div th:if="${mensaje}" class="alert alert-success"
       th:text="${mensaje}"></div>

  <main th:fragment="content">
    <!-- Contenido de cada página -->
  </main>

  <script th:src="@{/js/app.js}"></script>
</body>
</html>
lista.html 
<!-- templates/usuarios/lista.html -->
<html xmlns:th="http://www.thymeleaf.org">
<body>
  <h1 th:text="${titulo}">Lista</h1>

  <!-- Iteración con th:each -->
  <table>
    <thead><tr><th>ID</th><th>Nombre</th><th>Email</th><th>Acciones</th></tr></thead>
    <tbody>
      <tr th:each="u, stat : ${usuarios.content}"
          th:classappend="${stat.odd} ? 'fila-impar' : ''">
        <td th:text="${u.id}">1</td>
        <td th:text="${u.nombre}">Nombre</td>
        <td th:text="${u.email}">email</td>
        <td>
          <!-- URL dinámica con variables -->
          <a th:href="@{/usuarios/{id}(id=${u.id})}">Ver</a>
          <a th:href="@{/usuarios/{id}/editar(id=${u.id})}">Editar</a>
          <form th:action="@{/usuarios/{id}(id=${u.id})}" method="post"
                style="display:inline">
            <input type="hidden" name="_method" value="delete">
            <button type="submit"
                    th:onclick="'return confirm(\'¿Eliminar?\')'">
              Eliminar
            </button>
          </form>
        </td>
      </tr>
      <!-- Bloque si la lista está vacía -->
      <tr th:if="${#lists.isEmpty(usuarios.content)}">
        <td colspan="4">No hay usuarios</td>
      </tr>
    </tbody>
  </table>

  <!-- Paginación -->
  <div>
    <a th:if="${!usuarios.first}"
       th:href="@{/usuarios(page=${usuarios.number - 1})}">Anterior</a>
    <span th:text="${usuarios.number + 1} + '/' + ${usuarios.totalPages}"></span>
    <a th:if="${!usuarios.last}"
       th:href="@{/usuarios(page=${usuarios.number + 1})}">Siguiente</a>
  </div>
</body></html>

8.3 Referencia de directivas th:*

DirectivaUso
th:text="${var}"Muestra el valor de una variable (escapa HTML)
th:utext="${var}"Muestra HTML sin escapar (cuidado con XSS)
th:if / th:unlessCondicional: muestra el elemento si la expresión es true/false
th:each="item : ${lista}"Bucle sobre colecciones
th:href="@{/ruta}"URL con soporte para context path
th:src="@{/img/logo.png}"URL de recurso estático
th:action="@{/ruta}"Acción de formulario
th:value="${var}"Valor de un campo de formulario
th:field="*{campo}"Enlaza campo con propiedad del objeto del formulario
th:object="${objeto}"Define el objeto del formulario (en la etiqueta form)
th:class / th:classappendClase CSS dinámica
th:fragment / th:replaceFragmentos reutilizables (como include)
#lists.isEmpty(lista)Utilitario: comprobar si lista está vacía
#strings.length(texto)Utilitario: longitud de string
#dates.format(fecha,'dd/MM/yyyy')Formatear fechas
