1.1 Repaso Java imprescindible para Spring Boot

JavaRecordatorio.java 
// ── Anotaciones (Annotations) ─────────────────────────────────
// Las anotaciones son metadatos que Spring lee para configurar el comportamiento
@Component     // Marca la clase como bean de Spring (genérico)
@Service       // Bean de capa de servicio (semántico)
@Repository    // Bean de capa de acceso a datos
@Controller    // Bean de controlador MVC
@RestController // @Controller + @ResponseBody

// ── Generics ──────────────────────────────────────────────────
List<String> lista = new ArrayList<>();
Map<String, Integer> mapa = new HashMap<>();
Optional<Usuario> opt = Optional.of(usuario);

// ── Streams y lambdas (muy usados en Spring) ──────────────────
List<Usuario> admins = usuarios.stream()
    .filter(u -> u.getRol().equals("ADMIN"))
    .sorted(Comparator.comparing(Usuario::getNombre))
    .collect(Collectors.toList());

// ── Optional (evitar NullPointerException) ────────────────────
Optional<Usuario> opt = repositorio.findById(id);
Usuario u = opt.orElseThrow(() -> new RuntimeException("No encontrado"));
// O más limpio:
Usuario u2 = opt.orElse(new Usuario());
opt.ifPresent(usuario -> System.out.println(usuario.getNombre()));

// ── Records (Java 16+, muy usados como DTOs) ──────────────────
public record UsuarioDTO(Long id, String nombre, String email) {}
// Genera constructor, getters, equals, hashCode, toString automáticamente

// ── Interfaces funcionales y métodos de referencia ─────────────
usuarios.forEach(System.out::println);
usuarios.sort(Comparator.comparing(Usuario::getNombre));
Spring Boot usa características de Java moderno. Las más importantes: Anotaciones, Generics, Streams/Lambdas, Optional y Records (Java 16+).

1.2 Maven — Gestión de dependencias

Maven es la herramienta de build más usada con Spring Boot. El archivo pom.xml define las dependencias, plugins y configuración del proyecto.
pom.xml 
<!-- pom.xml — Estructura básica de un proyecto Spring Boot -->
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 ...">

  <modelVersion>4.0.0</modelVersion>

  <!-- Hereda configuración de Spring Boot -->
  <parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.3.0</version>
  </parent>

  <!-- Identificación del proyecto -->
  <groupId>com.miempresa</groupId>
  <artifactId>mi-app</artifactId>
  <version>1.0.0-SNAPSHOT</version>
  <packaging>jar</packaging>

  <properties>
    <java.version>21</java.version>
  </properties>

  <dependencies>
    <!-- Web + REST API -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <!-- JPA + Hibernate -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-data-jpa</artifactId>
    </dependency>
    <!-- Base de datos MySQL -->
    <dependency>
      <groupId>com.mysql</groupId>
      <artifactId>mysql-connector-j</artifactId>
      <scope>runtime</scope>
    </dependency>
    <!-- Seguridad -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-security</artifactId>
    </dependency>
    <!-- Validación -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-validation</artifactId>
    </dependency>
    <!-- Thymeleaf (plantillas HTML) -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-thymeleaf</artifactId>
    </dependency>
    <!-- Lombok (reduce boilerplate) -->
    <dependency>
      <groupId>org.projectlombok</groupId>
      <artifactId>lombok</artifactId>
      <optional>true</optional>
    </dependency>
    <!-- JWT -->
    <dependency>
      <groupId>io.jsonwebtoken</groupId>
      <artifactId>jjwt-api</artifactId>
      <version>0.12.3</version>
    </dependency>
    <!-- Testing -->
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-test</artifactId>
      <scope>test</scope>
    </dependency>
  </dependencies>

  <build>
    <plugins>
      <plugin>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-maven-plugin</artifactId>
      </plugin>
    </plugins>
  </build>
</project>

1.3 Estructura de un proyecto Spring Boot

Estructura del proyecto 
mi-app/
├── src/
│   ├── main/
│   │   ├── java/com/miempresa/miapp/
│   │   │   ├── MiAppApplication.java     ← Punto de entrada (@SpringBootApplication)
│   │   │   ├── config/
│   │   │   │   ├── SecurityConfig.java   ← Configuración Spring Security
│   │   │   │   └── JwtConfig.java
│   │   │   ├── controller/
│   │   │   │   ├── UsuarioController.java  ← @RestController
│   │   │   │   └── AuthController.java
│   │   │   ├── service/
│   │   │   │   ├── UsuarioService.java     ← Interfaz
│   │   │   │   └── UsuarioServiceImpl.java ← Implementación @Service
│   │   │   ├── repository/
│   │   │   │   └── UsuarioRepository.java  ← @Repository (JpaRepository)
│   │   │   ├── model/ (o entity/)
│   │   │   │   └── Usuario.java            ← @Entity
│   │   │   ├── dto/
│   │   │   │   ├── UsuarioDTO.java          ← Para respuestas API
│   │   │   │   └── UsuarioRequest.java      ← Para peticiones API
│   │   │   └── exception/
│   │   │       ├── GlobalExceptionHandler.java  ← @ControllerAdvice
│   │   │       └── RecursoNoEncontradoException.java
│   │   └── resources/
│   │       ├── application.properties      ← Configuración principal
│   │       ├── application-dev.properties  ← Perfil desarrollo
│   │       ├── application-prod.properties ← Perfil producción
│   │       └── templates/                  ← Plantillas Thymeleaf
│   └── test/
│       └── java/com/miempresa/miapp/
│           ├── controller/UsuarioControllerTest.java
│           └── service/UsuarioServiceTest.java
├── pom.xml
└── README.md
Regla de capas: Controller → Service → Repository → Entity. Nunca el Repository usa el Service.

1.4 Clase principal y application.properties

MiAppApplication.java 
// MiAppApplication.java — Punto de entrada
@SpringBootApplication  // = @Configuration + @EnableAutoConfiguration + @ComponentScan
public class MiAppApplication {
    public static void main(String[] args) {
        SpringApplication.run(MiAppApplication.class, args);
    }
}
application.properties 
# application.properties — Configuración completa

# ── Servidor ──────────────────────────────────────────────────
server.port=8080
server.servlet.context-path=/api

# ── Base de datos MySQL ────────────────────────────────────────
spring.datasource.url=jdbc:mysql://localhost:3306/mi_bd?useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=mipassword
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# ── JPA / Hibernate ───────────────────────────────────────────
spring.jpa.hibernate.ddl-auto=update
# none | validate | update | create | create-drop
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect

# ── Jackson (JSON) ────────────────────────────────────────────
spring.jackson.serialization.indent-output=true
spring.jackson.date-format=yyyy-MM-dd HH:mm:ss
spring.jackson.time-zone=Europe/Madrid

# ── Logging ───────────────────────────────────────────────────
logging.level.org.springframework.security=DEBUG
logging.level.org.hibernate.SQL=DEBUG
logging.level.com.miempresa=INFO

# ── Upload de archivos ────────────────────────────────────────
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB

# ── JWT (propiedades personalizadas) ──────────────────────────
app.jwt.secret=miClaveSecretaMuyLargaParaJWT512bits
app.jwt.expiration=86400000
