14.2 Ejercicio 1 — Componente con @Input/@Output

📝 EJERCICIO 1 — Nivel básico

Componente ProductoCard con @Input y @Output

Crea un componente ProductoCardComponent con: @Input() producto: Producto (requerido), @Output() añadirCarrito (emite el producto), @Output() verDetalle (emite el id). La card debe mostrar el nombre, precio con pipe currency en EUR, stock con ngClass (verde si > 0, rojo si 0) y dos botones. Si stock === 0, el botón de carrito debe estar deshabilitado.

ProductoCardComponent.ts
@Component({
  selector: 'app-producto-card',
  standalone: true,
  imports: [CommonModule, CurrencyPipe],
  template: `
    <div class='card'>
      <h3>{{ producto.nombre }}</h3>
      <p>{{ producto.precio | currency:'EUR' }}</p>
      <span [ngClass]="{'verde': producto.stock > 0, 'rojo': producto.stock === 0}">
        Stock: {{ producto.stock }}
      </span>
      <button (click)="onAñadir()" [disabled]="producto.stock === 0">
        Añadir al carrito
      </button>
      <button (click)="verDetalle.emit(producto.id)">Ver detalle</button>
    </div>
  `
})
export class ProductoCardComponent {
  @Input({ required: true }) producto!: Producto;
  @Output() añadirCarrito = new EventEmitter<Producto>();
  @Output() verDetalle = new EventEmitter<number>();

  onAñadir(): void {
    if (this.producto.stock > 0) this.añadirCarrito.emit(this.producto);
  }
}

14.3 Ejercicio 2 — Servicio + Reactive Form + HTTP

📝 EJERCICIO 2 — Nivel medio

Formulario de nueva reseña con Reactive Forms

Crea un componente NuevaReseñaComponent con Reactive Form: titulo (requerido, min 5, max 100), contenido (requerido, min 20), valoracion (requerido, número 1-5). Al hacer submit, llama a reseñaService.crear(). Muestra spinner durante la carga, mensaje de éxito o error. El botón submit debe estar deshabilitado mientras el form es inválido o carga.

NuevaReseñaComponent.ts
@Component({
  standalone: true,
  imports: [ReactiveFormsModule, CommonModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="onSubmit()">
      <input formControlName="titulo" placeholder="Título">
      <div *ngIf="f['titulo'].errors?.['required'] && f['titulo'].touched">Obligatorio</div>
      <textarea formControlName="contenido" placeholder="Contenido"></textarea>
      <input formControlName="valoracion" type="number" min="1" max="5">
      <div *ngIf="exito" class="success">Reseña creada correctamente</div>
      <div *ngIf="error" class="error">{{ error }}</div>
      <button type="submit" [disabled]="form.invalid || cargando">
        {{ cargando ? 'Enviando...' : 'Publicar reseña' }}
      </button>
    </form>
  `
})
export class NuevaReseñaComponent {
  private fb = inject(FormBuilder);
  private service = inject(ReseñaService);

  form = this.fb.group({
    titulo:    ['', [Validators.required, Validators.minLength(5), Validators.maxLength(100)]],
    contenido: ['', [Validators.required, Validators.minLength(20)]],
    valoracion: [null, [Validators.required, Validators.min(1), Validators.max(5)]],
  });

  get f() { return this.form.controls; }
  cargando = false; exito = false; error = '';

  onSubmit(): void {
    if (this.form.invalid) { this.form.markAllAsTouched(); return; }
    this.cargando = true; this.error = '';
    this.service.crear(this.form.value).subscribe({
      next: () => { this.exito = true; this.form.reset(); this.cargando = false; },
      error: (err) => { this.error = err.message; this.cargando = false; },
    });
  }
}
