13.2 Ejercicio 1 — Dockerfile PHP

📝 EJERCICIO 1 — Nivel básico

Dockerfile para aplicación PHP con Apache

Crea un Dockerfile que: use como base php:8.2-apache, instale las extensiones pdo_mysql y mbstring, active el módulo rewrite de Apache, copie el código fuente a /var/www/html, exponga el puerto 80 y use usuario www-data por seguridad.

Solución Ejercicio 1
FROM php:8.2-apache

RUN docker-php-ext-install pdo_mysql mbstring \
    && a2enmod rewrite \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /var/www/html

COPY . .

RUN chown -R www-data:www-data /var/www/html

USER www-data

EXPOSE 80

13.3 Ejercicio 2 — Docker Compose LAMP

📝 EJERCICIO 2 — Nivel medio

docker-compose.yml con stack LAMP completo

Crea un docker-compose.yml que levante: un servicio web (puerto 8080), un servicio db con MySQL 8.0 (persistencia en volumen nombrado), un servicio phpmyadmin (puerto 8081), una red bridge personalizada, y que web espere a que db esté healthy.

Solución Ejercicio 2
services:
  web:
    build: .
    ports:
      - '8080:80'
    environment:
      DB_HOST: db
      DB_NAME: app_db
      DB_USER: appuser
      DB_PASS: apppassword
    depends_on:
      db:
        condition: service_healthy
    networks:
      - lamp-net
    restart: unless-stopped

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: app_db
      MYSQL_USER: appuser
      MYSQL_PASSWORD: apppassword
    volumes:
      - mysql-data:/var/lib/mysql
    healthcheck:
      test: ['CMD', 'mysqladmin', 'ping', '-h', 'localhost']
      interval: 10s
      retries: 5
    networks:
      - lamp-net
    restart: unless-stopped

  phpmyadmin:
    image: phpmyadmin:5.2
    ports:
      - '8081:80'
    environment:
      PMA_HOST: db
    depends_on:
      - db
    networks:
      - lamp-net

volumes:
  mysql-data:

networks:
  lamp-net:
    driver: bridge

13.4 Ejercicio 3 — Multi-stage build Node.js

📝 EJERCICIO 3 — Nivel avanzado

Dockerfile multi-stage para app Node.js

Crea un Dockerfile multi-stage: stage builder usa node:20-alpine, instala dependencias y hace el build. Stage production usa node:20-alpine, crea usuario no-root "nodeuser", copia solo lo necesario del builder, define NODE_ENV=production, expone el puerto 3000 con HEALTHCHECK.

Solución Ejercicio 3
FROM node:20-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS production

RUN addgroup -g 1001 -S nodegroup && adduser -S nodeuser -u 1001 -G nodegroup

WORKDIR /app
ENV NODE_ENV=production

COPY --from=builder --chown=nodeuser:nodegroup /app/dist ./dist
COPY --from=builder --chown=nodeuser:nodegroup /app/node_modules ./node_modules
COPY --from=builder /app/package.json .

USER nodeuser
EXPOSE 3000

HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
    CMD wget -qO- http://localhost:3000/health || exit 1

CMD ['node', 'dist/index.js']
