5.1 Tipos de persistencia

Los contenedores son efímeros: cuando se elimina un contenedor, toda la información escrita en su capa de escritura se pierde. Para persistir datos (archivos de BD, uploads, logs...) necesitamos Volúmenes o Bind Mounts.

5.2 Comandos de volúmenes y bind mounts

Volúmenes y Bind Mounts
# ── Volúmenes nombrados ───────────────────────────────────────
docker volume create datos-mysql
docker volume ls
docker volume inspect datos-mysql
docker volume rm datos-mysql
docker volume prune                        # eliminar sin usar

# Usar volumen en contenedor
docker run -d \
  --name mysql-prod \
  -v datos-mysql:/var/lib/mysql \
  -e MYSQL_ROOT_PASSWORD=secret \
  mysql:8.0

# ── Bind Mounts ───────────────────────────────────────────────
# Montar carpeta de código (ideal para desarrollo)
docker run -d \
  --name app-dev \
  -v $(pwd)/src:/var/www/html \
  -p 8080:80 \
  php:8.2-apache

# Solo lectura
docker run -v $(pwd)/config:/etc/nginx:ro nginx

# ── Sintaxis --mount (más explícita, recomendada) ─────────────
docker run --mount type=volume,source=datos-mysql,target=/var/lib/mysql mysql:8.0
docker run --mount type=bind,source=$(pwd)/src,target=/var/www/html,readonly nginx
docker run --mount type=tmpfs,target=/tmp,tmpfs-size=100m nginx

# ── Backup de volumen ─────────────────────────────────────────
docker run --rm \
  -v datos-mysql:/data \
  -v $(pwd):/backup \
  ubuntu tar czf /backup/mysql-backup.tar.gz /data

# ── Restaurar volumen ─────────────────────────────────────────
docker run --rm \
  -v datos-mysql:/data \
  -v $(pwd):/backup \
  ubuntu tar xzf /backup/mysql-backup.tar.gz -C /
