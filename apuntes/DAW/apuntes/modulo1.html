1.1 El problema que resuelve Docker

El famoso problema "en mi máquina funciona" ocurre porque el software depende de librerías, versiones de lenguaje, configuraciones del SO y variables de entorno que difieren entre entornos de desarrollo, pruebas y producción. Docker lo resuelve empaquetando la aplicación junto con TODAS sus dependencias en un contenedor que se ejecuta de forma idéntica en cualquier máquina.
Beneficios clave de Docker:
• Portabilidad: el mismo contenedor corre igual en dev, test y producción
• Aislamiento: cada contenedor tiene su propio sistema de archivos, red y procesos
• Ligereza: comparte el kernel del host; arranca en segundos (vs minutos de VMs)
• Reproducibilidad: el Dockerfile describe exactamente cómo construir el entorno
• Escalabilidad: fácil replicar contenedores para manejar más carga
• DevOps/CI-CD: integración natural en pipelines de integración y despliegue continuo

1.3 Arquitectura de Docker

Docker Client (docker CLI): La herramienta de línea de comandos que usamos. Envía comandos al daemon via API REST.

Docker Daemon (dockerd): Proceso de fondo en el host. Gestiona imágenes, contenedores, redes y volúmenes.

Docker Images: Plantillas de solo lectura formadas por capas. Se crean con un Dockerfile.

Docker Containers: Instancias ejecutables de una imagen. Tienen su propia capa de escritura.

Docker Registry: Almacén de imágenes. Docker Hub es el público oficial. Pueden ser privados.

Dockerfile: Archivo de texto con instrucciones para construir una imagen.

Docker Compose: Herramienta para definir y ejecutar aplicaciones multi-contenedor.

Docker Network / Volume: Sistema de red virtual y mecanismo de persistencia de datos.

1.4 Flujo básico e Instalación

Flujo básico de Docker
# 1. Escribir el Dockerfile
# → Define cómo construir la imagen

# 2. Construir la imagen
docker build -t mi-app:1.0 .
# → Genera capas de solo lectura

# 3. Ejecutar el contenedor
docker run -d -p 8080:80 mi-app:1.0
# → Instancia de la imagen en ejecución

# 4. (Opcional) Subir la imagen al registro
docker push miusuario/mi-app:1.0
# → Disponible para otros equipos/servidores
Instalación en Ubuntu/Debian
# 1. Actualizar repositorios
sudo apt update && sudo apt upgrade -y

# 2. Instalar dependencias
sudo apt install -y apt-transport-https ca-certificates curl gnupg lsb-release

# 3. Añadir clave GPG oficial de Docker
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# 4. Añadir repositorio Docker
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list

# 5. Instalar Docker Engine
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 6. Verificar instalación
docker --version
docker compose version

# 7. Ejecutar sin sudo (añadir usuario al grupo docker)
sudo usermod -aG docker $USER
newgrp docker

# 8. Verificar que funciona
docker run hello-world
